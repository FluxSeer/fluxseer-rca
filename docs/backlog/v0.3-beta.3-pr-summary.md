# v0.3.0-beta.3 Candidate PR Summary

## Summary

This branch advances FluxSeer RCA from v0.3 product-direction planning into beta hardening for Kubernetes-native RCA state.

It keeps the project focused on read-only, evidence-verifiable RCA while improving the status surfaces needed by GitOps tools, dashboards, policy engines, and release reviewers.

## Changes

- Adds query retention policy for `InvestigationRequest`.
- Adds bounded provider egress attempt history.
- Persists provider primary/fallback egress decisions into canonical RCA status.
- Adds AgentAction status-first approval, dry-run, execution, and effectiveness projections.
- Documents architecture hardening contracts and ecosystem integration surfaces.
- Declares evidence store backend contract boundaries.
- Keeps compatibility fields where required for current beta users.

## Release Notes

This branch should be considered a `v0.3.0-beta.3` candidate because it contains additive API/CRD hardening relative to `v0.3.0-beta.2`.

Do not evaluate this branch with the beta.2 schema-freeze baseline as an unchanged-contract release.
