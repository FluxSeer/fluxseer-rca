# FluxSeer RCA Product Rename Plan

> **Superseded.** This is the original rename proposal and is kept as a
> historical record; some of its specifics (e.g. the CLI binary naming)
> differ from what was actually implemented. See
> [architecture/rename-migration-plan.md](../architecture/rename-migration-plan.md)
> for the plan that was executed and its current status.

This plan records the intended public rename from `FluxAgent` to `FluxSeer RCA`.
It is a product and artifact naming plan, not a v1alpha1 API migration.

## Decision

Use `FluxSeer RCA` as the product name going forward.

Keep the existing `FluxAgent` name as a compatibility alias for the current
published beta line until a dedicated rename release completes the public
artifact migration.

Recommended names:

| Surface | Target |
| --- | --- |
| Product display name | `FluxSeer RCA` |
| GitHub repository | `fluxseer-rca` |
| Go module | `github.com/FluxSeer/fluxseer-rca` |
| CLI binary | `fluxseer-rca` |
| Helm chart | `fluxseer-rca` |
| Operator image | `ghcr.io/fluxseer/fluxseer-rca/operator` |
| Demo image | `ghcr.io/fluxseer/fluxseer-rca/demo-observability` |
| Helm OCI chart | `oci://ghcr.io/fluxseer/fluxseer-rca/charts/fluxseer-rca` |

## Do Not Rename In This Cut

The following surfaces remain unchanged for the current v1alpha1 beta line:

```text
apiVersion: aiops.platform/v1alpha1
DataSource
InvestigationRequest
ModelProvider
RiskRule
RiskSignal
RemediationPlan
AgentAction
fluxagent_* metrics
fluxagent.aiops.platform/* annotations
```

These are Kubernetes API, metric, and compatibility contracts. Renaming them
requires a migration project with conversion, GitOps, RBAC, dashboard, alerting,
and upgrade guidance. That migration should be handled in a later API cut, not
as part of the public product rename.

## Repository Rename

Target repository:

```text
github.com/FluxSeer/fluxseer-rca
```

After the GitHub repository is renamed, local clones should update their remote:

```sh
git remote set-url origin git@github.com:FluxSeer/fluxseer-rca.git
```

or, for HTTPS:

```sh
git remote set-url origin https://github.com/FluxSeer/fluxseer-rca.git
```

GitHub redirects most repository URLs after a rename, but release automation,
badges, container labels, Go module imports, GitOps overlays, and external docs
should still be updated deliberately.

## Migration Phases

### Phase 1: Documentation Identity

- Introduce `FluxSeer RCA` as the public product name.
- Explain that `FluxAgent` remains the current compatibility artifact name.
- Update README, docs index, product requirements, open-source positioning, and
  competitive positioning.
- Keep release notes for old versions historically accurate.

### Phase 2: Public Artifact Rename

- Rename Helm chart from `fluxagent` to `fluxseer-rca`.
- Publish images under `ghcr.io/fluxseer/fluxseer-rca/*`.
- Rename the CLI binary to `fluxseer-rca`, with an optional `fluxagent`
  compatibility wrapper if needed.
- Update OCI labels, Makefile defaults, CI workflows, install examples, and
  GitOps overlays.
- Keep old image/chart tags immutable and document that they are historical.

### Phase 3: Source And Module Rename

- Rename the GitHub repository to `fluxseer-rca`.
- Rename the Go module to `github.com/FluxSeer/fluxseer-rca`.
- Update import paths, build metadata, generated manifests, release scripts, and
  documentation links.
- Run the full release gate before tagging the first release from the renamed
  module.

### Phase 4: Future API Review

Evaluate whether the Kubernetes API group should move away from
`aiops.platform/v1alpha1`.

This is explicitly out of scope for the product rename. A future API migration
must define conversion, upgrade, and compatibility behavior before any CRD group
or kind name changes.

## Acceptance Criteria

- README clearly presents `FluxSeer RCA` as the product name.
- Docs state that `FluxAgent` is the existing compatibility artifact name.
- GitHub repository metadata recommends `fluxseer-rca`.
- Release and install docs distinguish historical `fluxagent` artifacts from
  future `fluxseer-rca` artifacts.
- No CRD group, kind, metric, or annotation rename is performed without an
  explicit migration plan.

## Non-Goals

- No immediate CRD group rename.
- No mutation of published release tags or artifact tags.
- No compatibility-breaking Helm uninstall or CRD recreation.
- No attempt to claim `FluxAgent` artifacts disappear in already published beta
  releases.
