## Product Value

`v0.3.0-beta.1` turns FluxAgent from a read-only RCA workflow into a more auditable RCA control-plane contract.

Highlights:

- structured and auditable `InvestigationRequest.status`
- evidence-linked claims and independent verifier status
- durable provider execution checkpoints
- deterministic execution identity and finding identity
- incident occurrence and lineage tracking
- evidence provenance, digest, retention, and classification metadata
- datasource network safety and query policy boundaries
- hosted-provider data egress policy with explicit opt-in
- required evidence profiles and `NoIssueFound` gates
- raw-to-final replay coverage through deterministic fixtures
- low-cardinality RCA metrics and rule-pack validation

## Important Boundaries

This release keeps FluxAgent intentionally narrow:

- read-only applies to user workloads
- heuristic remains the no-secret default provider
- hosted-provider evidence transmission requires explicit `allowExternalTransmission=true`
- reasoning providers do not receive unrestricted cluster access
- confidence is a ranking score, not a calibrated probability
- `NoIssueFound` requires profile-specific evidence completeness
- provider calls are not exactly-once before durable checkpoint persistence
- bounded agentic investigation is not part of `v0.3.0-beta.1`
- remediation remains outside the core v0.3 RCA path
