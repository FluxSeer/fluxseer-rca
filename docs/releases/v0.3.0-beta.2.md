## Breaking Default Changes

The legacy annotation-driven `DeploymentRiskReconciler` is now disabled by default.

To preserve the `v0.3.0-beta.1` legacy annotation behavior, explicitly enable:

```yaml
features:
  legacyDeploymentRisk:
    enabled: true
```

The default installation no longer grants:

- cluster-wide Secret read permissions
- Job mutation permissions
- ConfigMap mutation permissions
- remediation/action write permissions

Hosted provider credentials are read from the `ModelProvider` namespace. The default chart grants Secret read permission only in the controller namespace.

## Product Boundary

Default install:

```text
Kubernetes-native read-only RCA
heuristic-first provider
no hosted provider egress
no legacy Deployment watcher
no remediation/action controllers
no experimental executor permissions
```

Explicit opt-in:

```text
hosted OpenAI / Claude / Gemini providers
legacy Deployment annotation detection
NormalizedSnapshot persistence
experimental remediation/action controllers
experimental executor permissions
```
